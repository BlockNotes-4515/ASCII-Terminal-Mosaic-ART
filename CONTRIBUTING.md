## Contributing

Contributions are welcome. If you would like to improve ASCII Terminal Mosaic ART, please follow the workflow below.

1. Fork the repository.
2. Create a new branch for your changes.
3. Follow the existing project structure and coding style.
4. Keep changes focused and avoid unnecessary modifications.
5. Test your changes before submitting a pull request.
6. Update the documentation when adding or modifying functionality.
7. Use clear and descriptive commit messages.
8. Do not commit credentials, API keys, temporary files, or generated files unnecessarily.
9. Provide a clear description of your changes in the pull request.
10. For major features or architectural changes, open an issue first to discuss the proposal.

### Development

```bash
git clone https://github.com/BlockNotes-4515/ASCII-Terminal-Mosaic-ART.git
cd ASCII-Terminal-Mosaic-ART

python -m venv .venv

```
Create a feature branch:
```bash
git checkout -b feature/your-feature-name

```
After testing your changes:
```bash
git add .
git commit -m "feat: describe your change"
git push origin feature/your-feature-name

.venv\Scripts\activate

pip install -r requirements.txt
```
Then open a Pull Request against the main branch.
