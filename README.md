# 🎭 Real-Time Terminal ASCII Graphics Engine

A lightweight, hardware-accelerated terminal graphics engine written in Python. Capable of rendering static images, full-motion true-color video streams, and interactive 3D wireframe meshes into high-density ASCII art.

## 🚀 Key Features

* **True-Color ANSI Support:** RGB-accurate text color rendering with 24-bit output.
* **Aspect-Ratio Correction:** Automatic terminal cell height compensation.
* **Frame-Accurate Video Playback:** Synchronized real-time playback via OpenCV frame buffers.
* **3D Projection Pipeline:** Full matrix-transformation pipeline for rendering 3D objects directly in terminal space.
